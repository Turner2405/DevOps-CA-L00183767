## Reporting a Vulnerability

We encourage responsible disclosure of security vulnerabilities. If you find something suspicious, we encourage and appreciate your report!

Ways to Report:
In order for the vulnerability reports to reach the maintainers as soon as possible, The preferred way is to use the "Report Vulnerability" button under the "Security" tab of the associated Github project.

This creates a private communication channel between the reporter and the maintainers.

Please include the following requested information listed below to help us better understand the nature and scope of possible issue:

* Type of issue if know (e.g. buffer overflow, SQL injection, cross-site scripting, etc)
* Full path of source file(s) related to the manifestation of the issure
* The location of the affected source code
* Any special configuration required to reproduce the issue
* Step-by-step instructions to reproduce the issue
* Proof-of-concept or exploit code (if possible)
* Impact of the issue, including how an attacker might exploit the issue

This information will help us triage your report more quickly.
